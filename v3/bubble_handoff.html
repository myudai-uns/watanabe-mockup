0. 推奨構築手順（この順が最小負担）

原則：「見た目」からではなく「データ→共通部品→表示→入力→複雑機能」の順。

  1. Option Set を作成（本書 §3）— 色属性も設定。UserRole（v3.1）も併せて作成。
  2. Data Type ＆ フィールドを作成（本書 §2）— リレーションを張る。User.role は UserRole 参照・User.is_active を追加。
  3. シードCSVを一括アップロード（別添 watanabe_db_*.csv）— 早期に実データで検証。
  4. Reusable Element を先に作成：ヘッダー/ナビ、ステータスバッジ（Option Set color駆動）、「タイトル帯＋コンテンツ」カード。
  5. 一覧・詳細の“表示のみ”を構築：受注一覧／顧客一覧／工場カンバン／変更履歴は Repeating Group。
  6. 入力フォーム＋workflow：受注起票・編集、見積パターン、税抜⇄税込換算、採番、保存（本書 §4）。
  7. 複雑機能は最後：カンバンD&D（Draggable Elementsプラグイン）／顧客メモ未保存警告（custom state）／見積PDF（PDFプラグイン）。
  8. 権限/privacy rules・レスポンシブ調整（本書 §5）。
  9. 検証：シードデータでモックと画面・計算・条件表示を1:1突合。

4. 計算・採番・条件ロジック

金額計算（消費税は一律10%）

  • 明細小計 OrderItem.subtotal は税抜（外税）で保持・自由入力。unit_price = round(subtotal / quantity)。
  • 受注小計 = Σ(明細subtotal)。値引き QuotePattern.discount_amount（税抜）を引き afterDiscount = max(0, 小計 − 値引き)。
  • 値引きは小計に按分：ratio = afterDiscount / 小計 を各明細に乗じてから税計算。
  • 受注は税額を3フィールドに分離保持（v3.1）：subtotal_ex_tax = afterDiscount（税抜小計・課税対象）／tax_amount = round(subtotal_ex_tax × 10%)（消費税）／total_amount = subtotal_ex_tax + tax_amount（税込合計）。顧客一覧/詳細の「税抜小計・消費税・税込」はこの3値を集計するため、列の整合が常に成立する。
  • 税抜⇄税込の相互換算：税込 = round(税抜 × 1.1)／税抜 = round(税込 × 100 / 110)。
  • 税込入力はUI上の換算のみ。DBは税抜（OrderItem.subtotal）だけを保持し、税込入力専用フィールドは作成しない。税込欄に入力された値は入力時に税抜へ正規化して保存する。

採番

  • 受注番号 = YYMMDD-連番3桁（当日同一prefixの既存件数 + 1、ゼロ埋め3桁）。例 260528-001。
  • 見積番号 = Q-YYMMDD-連番3桁。例 Q-260528-001。

ステータス連動

  • ステータスは Order.status 単一で管理（受注ステータスと工場ステータスを統一）。工場カンバンも Order.status の5列で表示。
  • status=印刷中 に変わったら FactoryRecord.started_at を現時刻でセット（未設定時）。
  • status=完成 または 納品済み で completed_at・completed_by をセット（未設定時）。
  • status=納品済み を選んだら delivered_date を当日でセット（未設定時）。
  • 納期超過表示：status ∉ {納品済み, 見積もり段階} かつ (本日 − 納期) > 0 のとき「N日経過」を表示。

値引き名目の表示解決（見積書）

  • discount_label_type = 自由記載 → discount_label_text を名目として表示（空なら「値引き」）。
  • = JA全農くみあい飼料㈱広告代負担金 → その名称をそのまま表示。
  • = 値引き → 「値引き」。
  • 自由記載のテキスト入力欄は「自由記載」選択時のみ表示。

条件付き表示

  • 値引き行：show_discount = yes かつ discount_amount > 0 のときのみ。
  • 納期区分=仮（tentative）：納期日必須を免除。範囲指定のみ終了日を有効化。
  • 受注「確認モード（view）」：全入力を読み取り専用（custom state で切替）。
  • 新規起票時のステータス選択肢は「見積もり段階／受注」のみ。
